# 🎈 Blank app template

A simple Streamlit app template for you to modify!

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://blank-app-template.streamlit.app/)

## Additional Tools

This repository now includes a comprehensive **Financial Ensemble Analysis Tool** (`single_ensemble.py`) that combines multiple machine learning models for investment analysis. See [README_ensemble.md](README_ensemble.md) for detailed documentation.

### Quick start with the ensemble tool:
```bash
python single_ensemble.py --ticker AAPL --fast
```

### How to run the Streamlit app

1. Install the requirements

   ```
   $ pip install -r requirements.txt
   ```

2. Run the app

   ```
   $ streamlit run streamlit_app.py
   ```
